Media servers

Add each Jellyfin-compatible server separately. You can name one “Silo”.

TMDB metadata

Add a TMDB API Read Access Token or v3 API key to load posters, backdrops, overview, genres, cast and crew. Get credentials from themoviedb.org/settings/api.

IMDb ratings & votes

For reliable IMDb rating and vote counts, add an OMDb API key. Get a key at omdbapi.com. The key is used by this browser to request title metadata.

Jellyfin username, password and access token are stored in this browser’s local storage. Use a dedicated low-privilege account, HTTPS and a trusted device. For a public deployment, a secure backend is preferable to storing credentials in browser storage. Your server must allow browser CORS requests from this page.
